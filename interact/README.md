## ohmyzsh

This benchmark replays the Oh My Zsh installer in a non-interactive mode, exercising the kind of prompt-driven, branching shell logic typical of installer scripts.

### Inputs

- `inputs/ohmyzsh/`: A shallow clone of the [Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh) repository, used as the installation source tree.

### Running

`ohmyzsh.sh` reads the user's environment, backs up any existing `.zshrc`, renders the bundled `zshrc.zsh-template` for the target `ZSH` directory, and optionally changes the login shell. The harness pipes canned responses to the prompts and points `ZDOTDIR` at the outputs directory so the resulting `.zshrc` lands under `outputs/`.

### Validation

Correctness is determined by computing the SHA-256 hash of each output file and comparing it against a reference hash stored in `hashes/`.

## shnake

This benchmark drives a shell-implemented Snake game by feeding it large streams of `w`/`a`/`s`/`d` keystrokes and recording the resulting `(x, y)` coordinate trace.

### Inputs

- `inputs/shnake_<size>`: A synthetic keystroke stream generated by
  `utils/create_inputs.py`. Larger sizes produce longer movement sequences.

### Running

`shnake.sh` reads keystrokes one character at a time, updates the current direction subject to the no-reverse rule, advances the snake's head position accordingly, and prints `x,y` for every accepted move. Whitespace is ignored and `q` terminates the run.

Outputs are stored as `outputs/shnake_<size>.out`.

### Validation

Correctness is determined by computing the SHA-256 hash of each output file and comparing it against a reference hash stored in `hashes/`.
